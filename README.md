Данный скрипт получает информацию об ОС("Windows","Linux"), версии ОС, версии ядра, архитектуре системы, процессоре и количестве ядер, определяет имя компьютера.
Учебная программа с помощью стандартных модулей Python определяет параметры и записывает результат в файл формата json. При выполнении задания не были использованы внешние модули.
